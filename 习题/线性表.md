# 链表逆序

```cpp
int reverseAndCount() {
    // 1. 拦截异常：如果是空表，或者只有 Dummy Head 没有数据节点，长度直接为 0
    if (head == nullptr || head - > next == nullptr) return 0;

    int length = 0;

    // 2. 物理定位：
    // prev 初始化为 nullptr，它将成为新链表的尾部（NULL）
    ListNode * prev = nullptr;
    // curr 从第一个“真实数据节点”开始进攻
    ListNode * curr = head - > next;

    while (curr != nullptr) {
        // 战术动作 1：在切断 curr 的后路之前，派 nextTemp 侦察兵记住下一个物理坐标
        ListNode * nextTemp = curr - > next;

        // 战术动作 2：指针物理回拨（逆序核心）
        curr - > next = prev;

        // 战术动作 3：防线整体向前推进
        prev = curr;
        curr = nextTemp;

        // 战术动作 4：记录真实击杀数（因为 curr 是从 head->next 开始的）
        length++;
    }

    // 此时，curr 已经坠入虚无（nullptr），而 prev 停留在原链表的最后一个节点。
    // 战术动作 5：重新锚定地基！让 Dummy Head 指向新的头节点（prev）
    head - > next = prev;

    return length;
}

```

# 性能优化

## 一、尾插优化
```c
 void insert(T var, int index) {
        if (index < 0 || index > size) {
            throw std::out_of_range("Invalid Index!");
        }
        Node* p = new Node(var);
        Node* a = dummyhead;
        for (int i = 0; i < index; i++) {
            a = a->next;
        }
        p->next = a->next;
        a->next = p;
        if (index == size) {
            tail = p;
        }
        size++;
    }
    void push_to_tail(T var) {
        Node* p    = new Node(var);
        tail->next = p;
        tail       = p;
        size++;
    }
```

**通过==维护tail==来减少尾插的时间复杂度（不会TLE）**



## 二、==**从头往后**==一个个getElement优化

加迭代器（改链表类）

在 `Linkedlist` 的 `public` 区里，构造函数之后插入这段：

```c
    // ── 迭代器 ───────────────────────────────────────────────
    class Iterator {
        Node* curr;
      public:
        Iterator(Node* n) : curr(n) {}
        T&        operator*()  { return curr->var; }
        Iterator& operator++() { curr = curr->next; return *this; }
        bool operator!=(const Iterator& o) const { return curr != o.curr; }
    };
    Iterator begin() { return Iterator(dummyhead->next); }
    Iterator end()   { return Iterator(nullptr); }
    // ────────────────────────────────────────────────────────
```

然后把 `main` 里的加法循环换成迭代器版本：

```c
    Linkedlist<int>           arr3;
    int                       carry = 0;
    Linkedlist<int>::Iterator it1   = arr1.begin();
    Linkedlist<int>::Iterator it2   = arr2.begin();
    while (it1 != arr1.end()) {
        int sum = *it1 + *it2 + carry;
        arr3.push_to_tail(sum % 10);
        carry = sum / 10;   // 比 bool add1 更通用
        ++it1;
        ++it2;
    }
    if (carry) {
        arr3.push_to_tail(1);
    }
```

#### 对比
==说人话就是：本来要拿0-n-1这么多数的值，如果每次都用getElement，复杂度是$n^2$,但是如果用一个指针从前往后走，只要遍历一次，复杂度就是n。==

|               | 原来                        | 改后                 |
| ------------- | ------------------------- | ------------------ |
| `getElem(i)`  | 每次从头走 i 步，O(i)            | 不再调用               |
| 加法循环          | 调用 getElem 2n 次，**O(n²)** | 两个迭代器各走一步，**O(n)** |
| Iterator `++` | —                         | 只移动一个指针，**O(1)     |
