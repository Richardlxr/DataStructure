## 判断链表里面有没有环

- **初始化指针**：定义两个指针，一个叫 `slow`（慢指针），一个叫 `fast`（快指针）。初始时，它们都指向链表的头节点（`head`）。
    
- **开始遍历**：
    
    - `slow` 指针每次向前移动**一**步（`slow = slow.next`）。
        
    - `fast` 指针每次向前移动**两**步（`fast = fast.next.next`）。
        
- **判断状态**：
    
    - **有环的情况**：如果链表存在环，`fast` 指针会先进入环内，并且一直在环里循环。随着时间推移，`slow` 指针也会进入环内。由于 `fast` 比 `slow` 每次多走一步，`fast` 最终一定会“从后面”追上 `slow`（即 `slow == fast`）。
        
    - **无环的情况**：如果链表没有环，`fast` 指针最终会跑到链表的尽头，遇到 `null`（即 `fast == null` 或 `fast.next == null`）。
        
- **得出结论**：如果指针相遇，说明有环；如果 `fast` 遇到 `null`，说明无环。

# 链表逆序

```cpp
int reverseAndCount() {
    // 1. 拦截异常：如果是空表，或者只有 Dummy Head 没有数据节点，长度直接为 0
    if (head == nullptr || head - > next == nullptr) return 0;

    int length = 0;

    // 2. 物理定位：
    // prev 初始化为 nullptr，它将成为新链表的尾部（NULL）
    ListNode * prev = nullptr;
    // curr 从第一个“真实数据节点”开始进攻
    ListNode * curr = head - > next;

    while (curr != nullptr) {
        // 战术动作 1：在切断 curr 的后路之前，派 nextTemp 侦察兵记住下一个物理坐标
        ListNode * nextTemp = curr - > next;

        // 战术动作 2：指针物理回拨（逆序核心）
        curr - > next = prev;

        // 战术动作 3：防线整体向前推进
        prev = curr;
        curr = nextTemp;

        // 战术动作 4：记录真实击杀数（因为 curr 是从 head->next 开始的）
        length++;
    }

    // 此时，curr 已经坠入虚无（nullptr），而 prev 停留在原链表的最后一个节点。
    // 战术动作 5：重新锚定地基！让 Dummy Head 指向新的头节点（prev）
    head - > next = prev;

    return length;
}

```

## 一、尾插优化
```c
 void insert(T var, int index) {
        if (index < 0 || index > size) {
            throw std::out_of_range("Invalid Index!");
        }
        Node* p = new Node(var);
        Node* a = dummyhead;
        for (int i = 0; i < index; i++) {
            a = a->next;
        }
        p->next = a->next;
        a->next = p;
        if (index == size) {
            tail = p;
        }
        size++;
    }
    void push_to_tail(T var) {
        Node* p    = new Node(var);
        tail->next = p;
        tail       = p;
        size++;
    }
```

**通过==维护tail==来减少尾插的时间复杂度（不会TLE）**



## 二、==**从头往后**==一个个getElement优化

加迭代器（改链表类）

在 `Linkedlist` 的 `public` 区里，构造函数之后插入这段：

```c
    // ── 迭代器 ───────────────────────────────────────────────
    class Iterator {
        Node* curr;
      public:
        Iterator(Node* n) : curr(n) {}
        T&        operator*()  { return curr->var; }
        Iterator& operator++() { curr = curr->next; return *this; }
        bool operator!=(const Iterator& o) const { return curr != o.curr; }
    };
    Iterator begin() { return Iterator(dummyhead->next); }
    Iterator end()   { return Iterator(nullptr); }
    // ────────────────────────────────────────────────────────
```

然后把 `main` 里的加法循环换成迭代器版本：

```c
    Linkedlist<int>           arr3;
    int                       carry = 0;
    Linkedlist<int>::Iterator it1   = arr1.begin();
    Linkedlist<int>::Iterator it2   = arr2.begin();
    while (it1 != arr1.end()) {
        int sum = *it1 + *it2 + carry;
        arr3.push_to_tail(sum % 10);
        carry = sum / 10;   // 比 bool add1 更通用
        ++it1;
        ++it2;
    }
    if (carry) {
        arr3.push_to_tail(1);
    }
```

#### 对比
==说人话就是：本来要拿0-n-1这么多数的值，如果每次都用getElement，复杂度是$n^2$,但是如果用一个指针从前往后走，只要遍历一次，复杂度就是n。==

|               | 原来                        | 改后                 |
| ------------- | ------------------------- | ------------------ |
| `getElem(i)`  | 每次从头走 i 步，O(i)            | 不再调用               |
| 加法循环          | 调用 getElem 2n 次，**O(n²)** | 两个迭代器各走一步，**O(n)** |
| Iterator `++` | —                         | 只移动一个指针，**O(1)     |

# 循环双向链表的实现（可用于解决约瑟夫环）

```c
 public:
     // 1. 构造函数：初始化哨兵节点
     DoublyCircularLinkedList() {
         head = new Node(0); // 哨兵节点不存储有效数据
         head - > next = head; // 循环：自己指向自己
         head - > prev = head;
         _size = 0;
     }

 // 5. 在任意指定节点 p 之前插入新节点 (核心基础函数)
 // 无论是头插、尾插，本质都是在某个节点前插入
 void insertBefore(Node * p, int val) {
     Node * newNode = new Node(val);
     Node * prevNode = p - > prev;

     // 调整 4 个指针的指向
     newNode - > next = p;
     newNode - > prev = prevNode;
     prevNode - > next = newNode;
     p - > prev = newNode;

     _size++;
 }
```


```c
    // 7. 头部插入 (头插法)
    // 提示：带有哨兵位时，头插其实就是插入到 head->next 之前
    void push_front(int val) {
        insertBefore(head - > next, val);
    }

    // 8. 尾部插入 (尾插法)
    // 提示：因为是循环链表，head->prev 永远指向最后一个有效节点，所以尾插就是插入到 head 之前
    void push_back(int val) {
        insertBefore(head, val);
    }
```
