#### 1. 图的分类与基础定义

- **结点/顶点 (Vertex)**：图的基本元素。在有向图中，边由**弧尾（初始结点）**指向**弧头（终止结点）** 。
    
- **无向图 (Undirected Graph)**：边没有方向，通常用小括号表示边，如 $(V_i, V_j)$。常用于表示合作网络等双向关系 。
    
- **有向图 (Directed Graph)**：边有方向（也叫弧），通常用尖括号表示弧，如 $<V_i, V_j>$。常用于表示文献引用、网页链接等单向关系 。
    
- **加权图 / 网络 (Weighted Graph / Network)**：图的边附带有“权值”（如距离、成本、时间等） 。
    

#### 2. 顶点的度 (Degree)

衡量一个顶点的“连接程度”。

- **无向图**：直接与该顶点相连的边的总数 。
    
- **有向图**：分为**出度 (Out-degree)**（从该顶点发出的弧的数量）和**入度 (In-degree)**（指向该顶点的弧的数量） 。
    

#### 3. 连通性 (Connectivity)

**对于无向图：**

- **路径 (Path)**：由顶点 $v_i$ 到 $v_j$ 之间的顶点序列 。
    
- **简单回路 / 简单环**：除第一个和最后一个顶点相同外，其余顶点**不重复出现**的路径 。
    
- **连通图**：任意两点之间都有路径相连 。
    
- **连通分量 (Connected Component)**：无向图的**极大连通子图**（不能再扩充的连通块） 。
    

**对于有向图：**

- **强连通图**：任意两点之间都存在**双向路径**（即 $v_i$ 能到 $v_j$，$v_j$ 也能到 $v_i$） 。
    
- **弱连通图**：把有向边当成无向边看，如果它是连通的，就叫弱连通图 。
    
- **强连通分量**：有向图的**极大强连通子图** 。
    

#### 4. 树与完全图 (特殊形态的图)

- **生成树 (Spanning Tree)**：极小连通子图。包含全部 $n$ 个结点，但只有恰好 $n-1$ 条边。如果加上任何一条新边，必定会形成回路 。
    
- **无向完全图**：任意两个顶点间都有一条边，总边数为 $n(n-1)/2$ 。
    
- **有向完全图**：任意两个顶点间都有方向相反的两条边，总边数为 $n(n-1)$ 。
    

### 图的存储结构 (Graph Storage)

#### 方案一：邻接矩阵 (Adjacency Matrix)

**核心思想**：用一个二维数组（矩阵）来表示所有的边。

- **机制**：设图有 $n$ 个顶点，建立一个 $n \times n$ 的布尔矩阵 `A` 。
    
    - 如果有向图从顶点 $i$ 到 $j$ 有一条边，则 `A[i][j] = 1`（无边则为 `0`） 。
        
    - 如果是加权图，有边则存权值 `A[i][j] = weight`，无边则存一个特殊标记（如 `∞` 或 `-1`） 。
        
- **无向图特权**：无向图的邻接矩阵一定是对称的（因为 $i$ 到 $j$ 有边，$j$ 到 $i$ 必定有边）。顶点的度就是第 $i$ 行（或列）的元素之和 。
    
- **优缺点**：
    
    - ✅ **优点**：查找任意两点间是否有边极其快速（时间复杂度 $O(1)$） 。
        
    - ❌ **缺点**：极其浪费空间。即使图里只有几条边，也要强行开辟 $n^2$ 的内存空间（空间复杂度 $O(|V|^2)$） 。适合稠密图。
        

#### 方案二：邻接表 (Adjacency List)

**核心思想**：数组 + 单链表的组合拳。只存实际存在的边，绝不浪费。

- **机制**：
    
    - 用一个一维数组（或顺序表）保存所有的顶点 。
        
    - 每个顶点都拖着一条单链表，链表里装的都是它的“邻接点”（无向图）或“出度目标点”（有向图） 。
        
- **空间消耗**：只需要 `结点数 + 边数` 的空间（空间复杂度 $O(|V| + |E|)$），对内存极其友好 。
    
- **优缺点**：
    
    - ✅ **优点**：极度省空间，适合边较少的稀疏图 。找一个顶点的所有邻居非常快。
        
    - ❌ **缺点**：想判断顶点 A 和顶点 B 是否直接相连，只能老老实实去遍历 A 的那条单链表，速度不如矩阵快。

```c
    struct edgeNode {
        int end; // 终点在顶点数组中的下标
        TypeOfEdge weight; // 边的权值
        edgeNode * next; // 指向下一个边结点的指针
        edgeNode(int e, TypeOfEdge w, edgeNode * n = NULL) {
            end = e;
            weight = w;
            next = n;
        }
    };

    // 保存顶点的数据元素类型
    struct verNode {
        TypeOfVer ver; // 顶点值
        edgeNode * head; // 对应的单链表的头指针
        verNode(edgeNode * h = NULL) {
            head = h;
        }
    };
```

1. **需求：“我要知道这片大陆有多大？都有哪些城市？”**
   👉 **标准图论 DFS**（传染病模型，打标记绝不擦除，快速扫图）。
   
2. **需求：“我要找从A城到B城的最短距离！”**
   👉 **图论 BFS（广度优先搜索）**（像水波纹一样一圈圈扩散，最先碰到的肯定是最短的）。

3. **需求：“我要找出从A城到B城的【任意一条】走得通的路即可。”**
   👉 **标准图论 DFS**（走到B城立刻喊停，把刚才经过的节点打印出来，就是一条路。虽然不一定最短，但能用）。

4. **需求：“我要找出从A城到B城的【所有可能】的路线！” 或者 “我要穷举所有的密码组合！”**
   👉 **回溯 DFS**（也就是你写的素数环模板。必须用 `used = false` 擦除标记！走完一条路，退回去，擦掉记号，重新换条路走。这叫“平行宇宙”模型）。
