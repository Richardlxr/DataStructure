# 📚 调度场算法

## 一、 核心概念：为什么需要栈？
普通算式（中缀表达式）符合人类阅读习惯，但对计算机不友好，因为必须考虑**优先级**和**括号**。
逆波兰表达式（后缀表达式）的本质是：**把运算符放在它真正要执行的那一刻，彻底消除括号。**

为了实现转换，我们需要借用一个**栈**，可以把它理解为**“运算符的候车室”**：
* 遇到必须先算的（高优先级），直接发车（输出）。
* 遇到还得等等看的（低优先级），先进候车室（入栈）排队。

---

## 二、 符号的优先级定义
我们为常见运算符设定优先级：
* **级别 2（高）**：`*`，`/`
* **级别 1（低）**：`+`，`-`
* **特殊（墙）**：`(`，`)`

---

## 三、 调度场算法：完整规则说明

准备两个容器：一个是**输出列表**（存最终的逆波兰表达式），一个是**符号栈**。从左到右遍历算式：

1. **遇到数字**：
   * **直接输出**到列表。（数字永远不需要进候车室）
2. **遇到普通运算符（`+`、`-`、`*`、`/`）**：
   * 比较当前运算符与**栈顶**运算符的优先级。
   * 只要 ==**`栈顶优先级 >= 当前优先级`**==，就把栈顶弹出并输出。（**重点：持续比较并弹出，直到栈空、遇到左括号、或者栈顶优先级严格小于当前优先级为止**）。
   * 将当前运算符**入栈**。
3. **遇到左括号 `(`**：
   * **无条件入栈**。它相当于在栈里建立了一道“不可跨越的墙”。之后的运算符不能把墙外面的符号挤出栈。
4. **遇到右括号 `)`**：
   * **开始疯狂出栈并输出**，直到栈顶是左括号 `(` 为止。
   * 接着把左括号 `(` 弹出并**扔掉**（拆墙）。右括号本身也不入栈。
5. **算式遍历结束**：
   * 将栈里剩下的所有运算符依次**弹出并输出**。

## 四、 核心原理解析：为什么规则能涵盖所有情况？

| 数学逻辑                | 算法实现原理                                                 | 例子表现                                             |
| :------------------ | :----------------------------------------------------- | :----------------------------------------------- |
| **高优先级先算** (先乘除后加减) | **低遇高（不弹）**：当前级别低，无法触发 `栈顶>=当前`。高级符号压在上面，最后先出栈。        | 读 `1+2*3`，`*` 直接压在 `+` 上，输出 `1 2 3 * +`          |
| **高优先级及时变现**        | **高遇低（弹出）**：栈顶是高级别，满足 `>=`。高级符号马上出栈运算。                 | 读 `2*3+4`，读到 `+` 时，`*` 立马出栈，输出 `2 3 * 4 +`       |
| **同级从左到右算** (结合性)   | **同级相遇（弹出）**：满足 `=`。先来的先出栈。                            | 读 `1-2+3`，读到 `+` 时，前面的 `-` 出栈，输出 `1 2 - 3 +`     |
| **括号内优先计算**         | **左括号建墙，右括号清算**：括号内的符号不会受外层符号影响，遇到 `)` 时墙内符号被强行提前打包计算。 | 读 `(1+2)*3`，`1+2` 在墙内，读到 `)` 立刻出栈，输出 `1 2 + 3 *` |

## 五、 实战演练速查

### 经典场景 1：同级与高级混合运算（无括号）
**算式： `3 + 5 / 2 * 4 - 1`**

| 当前字符 | 动作关键点 | 符号栈 (底->顶) | 当前输出 (逆波兰) |
| :--- | :--- | :--- | :--- |
| `3` | 数字直接输出 | `[]` | `3` |
| `+` | 栈空，入栈 | `[+]` | `3` |
| `5` | 数字输出 | `[+]` | `3 5` |
| `/` | 级2 > 级1，`/` 入栈 | `[+, /]` | `3 5` |
| `2` | 数字输出 | `[+, /]` | `3 5 2` |
| `*` | **同级相遇！** `/` (级2) `>=` `*` (级2)，`/` 出栈。`*` 压在 `+` 上。 | `[+, *]` | `3 5 2 /` |
| `4` | 数字输出 | `[+, *]` | `3 5 2 / 4` |
| `-` | **终极连弹！** `*`出栈，`+`也出栈。`-`入栈。 | `[-]` | `3 5 2 / 4 * +` |
| `1` | 数字输出 | `[-]` | `3 5 2 / 4 * + 1` |
| 结束 | 清空栈，弹出 `-` | `[]` | **`3 5 2 / 4 * + 1 -`** |

### 经典场景 2：带括号的运算
**算式： `1 + 2 * ( 4 - 1 )`**

| 当前字符 | 动作关键点 | 符号栈 (底->顶) | 当前输出 (逆波兰) |
| :--- | :--- | :--- | :--- |
| `1`, `+`, `2`| 常规操作 | `[+]` | `1 2` |
| `*` | 遇 `+` 不弹，直接入栈 | `[+, *]` | `1 2` |
| `(` | **左括号建墙** | `[+, *, ( ]` | `1 2` |
| `4` | 数字输出 | `[+, *, ( ]` | `1 2 4` |
| `-` | **遇到墙**，把 `(` 当作最低级，`-` 入栈 | `[+, *, (, -]` | `1 2 4` |
| `1` | 数字输出 | `[+, *, (, -]` | `1 2 4 1` |
| `)` | **右括号清算！** 弹出 `-`，扔掉 `(` 拆墙。 | `[+, *]` | `1 2 4 1 -` |
| 结束 | 清空栈，弹出 `*` 再弹 `+` | `
