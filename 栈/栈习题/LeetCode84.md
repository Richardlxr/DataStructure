
# 📚 算法核心笔记：柱状图中最大的矩形 (LeetCode 84)

## 一、 核心概念：为什么需要“单调栈”？

首先，我们要明白一个常识：**木桶效应**。
一个矩形能向左向右延伸多宽，完全取决于这片区域里**最矮的那根柱子**。

*   **暴力的想法**：遍历每一根柱子，把它当做“最矮的柱子”，然后向左找、向右找，直到碰到比它还矮的柱子停下来。这决定了它的最大宽度。（复杂度 $O(N^2)$，会超时）
*   **单调栈的破局点**：我们不需要每次都重新向左向右找！我们可以开一个“**高度候车室（栈）**”。
    *   如果后来的柱子越来越高，说明前面的柱子还能继续向右延伸，大家都进候车室排队。
    *   一旦来了一根**矮柱子**，它就像一个“终结者”，宣告了前面那些高柱子**向右延伸的极限（右边界）**到了！此时，高柱子就可以出栈并计算最大面积了。

---

## 二、 单调栈的运作规则（寻找左右边界）

为了方便计算宽度，**栈里存的不是高度，而是柱子的“索引（下标）”**。
我们维护一个**单调递增栈**（栈底到栈顶对应的柱子高度越来越大）。

1.  **遇到比栈顶“高”或“相等”的柱子**：
    *   说明栈顶柱子还能向右延伸，直接将当前柱子的索引**入栈**。
2.  **遇到比栈顶“矮”的柱子**：
    *   **触发清算！** 这根矮柱子就是栈顶柱子的**右边界**。
    *   将栈顶元素**弹出**，这就是我们当前要计算的“基准高度”柱子。
    *   弹出后，此时的**新栈顶**，就是这根基准柱子的**左边界**。（因为栈是单调递增的，压在基准柱子下面的，一定是它左边第一个比它矮的柱子）。
    *   **计算面积**：`高度 = heights[弹出的索引]`，`宽度 = 右边界索引 - 左边界索引 - 1`。
    *   持续比较并弹出，直到栈顶柱子比当前矮为止，然后把当前索引入栈。

### 🌟 神级技巧：首尾加“哨兵 (Dummy Node)”
为了避免边界条件（比如一直递增导致不出栈，或者弹空了找不到左边界），我们给原数组**头尾各加一个高度为 `0` 的柱子**：
*   **头部的 `0`**：永远垫在栈底，保证栈永远不会空，所有弹出的柱子都能顺利找到“左边界”。
*   **尾部的 `0`**：作为最后的“终结者”，它的高度为0，比所有真实的柱子都矮，能把栈里所有剩余的柱子全部逼出来清算。

## 三、 核心原理解析：凭什么这样能算出最大面积？

| 面积决定因素          | 算法如何完美解决                                                               | 例子表现                                         |
| :-------------- | :--------------------------------------------------------------------- | :------------------------------------------- |
| **高度**          | 每次出栈的元素，就是当前被锁定的“基准高度”。所有柱子都会进栈一次、出栈一次，意味着**每根柱子都会被当做一次基准高度来计算**，绝不遗漏。 | 处理 `[2,1,5,6]` 时，`6`出栈算一次高度6的，`5`出栈算一次高度5的。  |
| **右边界** (在哪被卡住) | **高遇低，右边卡死**：当前元素比栈顶矮，说明当前元素就是阻碍栈顶继续向右扩张的第一根柱子。                        | 遇到 `2` 时，栈顶是 `6`，`2`就是`6`过不去的右边界。            |
| **左边界** (在哪被卡住) | **单调递增的栈底，左边卡死**：因为栈里高度是严格递增的，所以压在出栈元素底下的那个元素，必然是左边第一个比它矮的柱子。          | 栈里是 `[1, 5, 6]`，`6`的左边界必定是`5`，`5`的左边界必定是`1`。 |
| **宽度计算**        | `右边界索引 - 左边界索引 - 1`，这个数学公式完美去除了左右两根阻碍柱的宽度，留下的是**纯粹的可延伸宽度**。            | 左边界索引2，右边界索引5。可用区间是3、4。宽度 = 5 - 2 - 1 = 2。   |

## 四、 实战演练速查 (硬核推演例子)

我们以经典数组 `[2, 1, 5, 6, 2, 3]` 为例。
**第一步：首尾加哨兵 0**，数组变成 **`[0, 2, 1, 5, 6, 2, 3, 0]`**。
我们准备一个栈（存下标），一个变量记录最大面积 `MaxArea`。

| 索引 `i` | 当前高度 | 栈的情况与比较 (栈内存的是索引) | 动作分析 (弹出的高度、宽度、面积) | 当前MaxArea | 栈更新后 (底 -> 顶) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `0` | `0`(哨兵) | 栈空 | 头部哨兵无条件入栈 | `0` | `[0]` |
| `1` | `2` | 高度 `2 > 0` | 递增，直接入栈 | `0` | `[0, 1]` |
| `2` | `1` | 高度 `1 < 2`，**触发清算** | **弹出1**：高`h=2`。<br>左边界`栈顶=0`，右边界`i=2`<br>宽`w=2-0-1=1`。面积`2*1=2` | **`2`** | `[0, 2]` (压入当前1的索引) |
| `3` | `5` | 高度 `5 > 1` | 递增，直接入栈 | `2` | `[0, 2, 3]` |
| `4` | `6` | 高度 `6 > 5` | 递增，直接入栈 | `2` | `[0, 2, 3, 4]` |
| `5` | `2` | 高度 `2 < 6`，**触发清算1** | **弹出4**：高`h=6`。<br>左界`3`，右界`5`。宽`5-3-1=1`。<br>面积`6*1=6`。 | **`6`** | `[0, 2, 3]` (暂存) |
| *(续)* | `2` | 高度 `2 < 5`，**触发清算2** | **弹出3**：高`h=5`。<br>左界`2`，右界`5`。宽`5-2-1=2`。<br>面积`5*2=10`。 | **`10`** | `[0, 2]` (暂存) |
| *(续)* | `2` | 高度 `2 > 1` (栈顶的2对应高度1) | 清算停止。当前2的索引入栈。 | `10` | `[0, 2, 5]` |
| `6` | `3` | 高度 `3 > 2` | 递增，直接入栈 | `10` | `[0, 2, 5, 6]` |
| `7` | `0`(尾哨) | 高度 `0 < 3`，**触发清算1** | **弹出6**：高`h=3`。<br>左`5`右`7`，宽1，面积`3` | `10` | `[0, 2, 5]` (暂存) |
| *(续)* | `0` | 高度 `0 < 2`，**触发清算2** | **弹出5**：高`h=2`。<br>左`2`右`7`，宽4，面积`8` | `10` | `[0, 2]` (暂存) |
| *(续)* | `0` | 高度 `0 < 1`，**触发清算3** | **弹出2**：高`h=1`。<br>左`0`右`7`，宽6，面积`6` | `10` | `[0]` (暂存) |
| *(续)* | `0` | 遇到底部的首哨兵 `0` | 清算停止，入栈。遍历结束！ | **`10`** | `[0, 7]` |

**最终结果**：最大面积为 `10`。（即高度为5和6的两根柱子，拼出的高度为5、宽度为2的矩形）。

## 五、 重点口诀总结

在面试或复习时，只要默念这三句话，代码就能行云流水地写出来：

1. **“求最大面积，本质是为每一根柱子寻找其左右第一个比它矮的柱子。”**
2. **“栈存索引递增排。遇到矮子就清算，矮子是右界，新栈顶是左界。”**
3. **“首尾各加一个零。首零防越界，尾零全清空。”**
