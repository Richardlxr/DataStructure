### 第四阶段：单调栈（Monotonic Stack）—— 物理预测力
*   **核心目标**：掌握一种“能够看见未来”的数据结构。
*   **核心课题**：如何通过维护栈内元素的单调性，将 O(n²) 的暴力搜索物理降维成 O(n)。
*   **实战题目**：
    1.  **每日温度 (Next Greater Element)**：理解如何用栈记录“尚未解决的遗憾”。（LeetCode 739)
	    ```c
		class Solution {
		    public: vector < int > dailyTemperatures(vector < int > & temperatures) {
		        int n = temperatures.size();
		        vector < int > answer(n, 0);

		        // 1. 防御性检查：如果是空数组，直接返回
		        if (n == 0)
		            return answer;

		        // 2. 预分配栈空间：避免 doubleSpace() 的物理开销
		        ArrayStack < int > s(n);

		        // 3. 核心物理循环：每一个 i 只进场一次
		        for (int i = 0; i < n; i++) {
		            // 只要当前温度比栈顶（那些还在等待的人）高
		            while (!s.isEmpty() && temperatures[i] > temperatures[s.top()]) {
		                int prevIndex = s.top();
		                s.pop();
		                // 物理结算：计算位置差
		                answer[prevIndex] = i - prevIndex;
		            }
		            // 无论如何，当前这一天都要入栈（要么它是别人的答案，要么它在等答案）
		            s.push(i);
		        }
		        return answer;
		    }
		};
	    ```
    2.  **环形单调栈**（LeetCode 503）
	3.  **柱状图中最大的矩形**：这是单调栈的终极试炼，要求你能在脑海中画出矩形阴影在内存中膨胀和收缩的过程。

### 第六阶段：工业级健壮性优化（毕业设计）
*   **核心目标**：让你的栈不仅跑得快，而且杀不死。
*   **核心课题**：
    1.  **线程安全栈**：初步接触锁（Mutex）与竞争条件（Race Condition），思考如果两个线程同时抢一个栈顶指针会发生什么。
    2.  **Move Semantics（移动语义）**：升级你的栈，支持 C++11 的 `std::move`，减少不必要的内存拷贝。
