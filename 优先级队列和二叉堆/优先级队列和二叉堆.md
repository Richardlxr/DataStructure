
# 实现细节


## 哨兵
- `data[0]`我们放成`std::numeric_limits<T>::min()`,(需要`#include <limits>`)，主要是为了代数方便

- 对于数组中任意一个下标为 

```
i
```

 的节点：

- 它的**左孩子**一定在数组的： 
    
    ```
    2×i
    ```
    
     位置
    
- 它的**右孩子**一定在数组的： 
    
    ```
    2×i+1
    ```
    
     位置
    
- 它的**父节点**一定在数组的： 
    
    ```
    ⌊i/2⌋
    ```
    
    （向下取整） 位置


## 入队

```cpp
    void queue(T _data) {
        int hole = ++size;

        while (_data < data[hole >> 1]) {
            data[hole] = data[hole >> 1];
            hole = hole >> 1;
        }
        data[hole] = _data;
    }
```
