### 第一步：理解 `stage` 到底是什么？——它叫“书签”

假设你在看一本小说（执行函数）。
突然，你妈叫你去打酱油（发生了递归调用）。
你离开前会做什么？你会在你看的那一页**夹一个书签**，对吧？
等你打完酱油回来，你只要翻到书签那一页，就能**接着往下看**，而不会从第一页重新看。

代码里的 `stage`，就是这个**书签**。
因为递归函数在调用自己时，原来的函数**暂停了**。当子函数执行完毕返回时，原来的函数需要知道：“我刚才执行到哪一行代码了？接下来该执行哪行？”

### 第二步：“切香肠”法则（核心秘籍）

怎么确定一个递归有几个 `stage`？
**规则：寻找所有的“递归调用语句”，在它们后面重重地划一刀！**

被切出来的每一段，就是一个 `stage`。

我们拿最经典的**斐波那契数列**来切香肠：

```cpp
struct frame {
    int parameter; // 参数 n
    int a; // 保存 fib(n-1) 的结果
    int b; // 保存 fib(n-2) 的结果
    int stage; // 阶段（0, 1, 2）
};

int NonRecursion_fib(int n) {
    int ret_val = 0; // 公共信箱
    std::stack < frame > s;
    s.push({
        n,
        0,
        0,
        0
    });

    while (!s.empty()) {
        frame curr = s.top();
        s.pop(); // 先拿出来

        switch (curr.stage) {
            case 0: {
                // 如果 n <= 1，直接可以出结果了
                if (curr.parameter <= 1) {
                    ret_val = curr.parameter; // 【下班前，把成果放进信箱】
                    // 注意：因为前面已经 pop 过了，而且这里没有 push
                    // 所以 break 之后，这个节点就彻底消失了（完美模拟了 return n;）
                    break;
                }

                // 如果 n > 1，需要去求 fib(n-1)
                curr.stage++; // 把自己升级为 stage 1

                // 因为是栈，要先让别人干活，所以【先把未来的自己压底，再把新任务放上面】
                s.push(curr); // 压回升级后的自己
                s.push({
                    curr.parameter - 1,
                    0,
                    0,
                    0
                }); // 派小弟去算 fib(n-1)

                break; // ！！千万别忘了 break ！！
            }
            case 1: {
                // 什么时候会进 case 1？
                // 只有当小弟 fib(n-1) 算完，并且彻底消失后，身为 stage 1 的自己才会重见天日。

                // 【刚醒来，先去信箱拿信】
                // 此时 ret_val 里装的一定是小弟 fib(n-1) 算出来的结果！
                curr.a = ret_val;

                // 接下来要去算 fib(n-2) 了
                curr.stage++; // 把自己升级为 stage 2

                s.push(curr); // 压回升级后的自己
                s.push({
                    curr.parameter - 2,
                    0,
                    0,
                    0
                }); // 派另一个小弟去算 fib(n-2)

                break;
            }
            case 2: {
                // 什么时候会进 case 2？
                // 只有当第二个小弟 fib(n-2) 算完消失后，自己才会再次重见天日。

                // 【刚醒来，先去信箱拿信】
                // 此时 ret_val 里装的一定是第二个小弟 fib(n-2) 的结果！
                curr.b = ret_val;

                // 所有小弟都算完了，该自己做总计算了： return a + b;
                ret_val = curr.a + curr.b; // 【下班前，把最终总成果放进信箱】

                // 重点：我的所有活都干完了！所以我 **绝对不 push 自己**。
                // 就让我在内存中灰飞烟灭吧~

                break;
            }
        }
    }

    // 当栈彻底空了，信箱里的最后那封信，就是我们要的最终答案
    return ret_val;
}
```

### 第三步：刻意练习（用“切香肠”秒杀二叉树遍历）

我们再回头看看你最初学的**二叉树遍历**。你学到的通常是很精简的非递归写法，但如果用我们的套路，其实极其简单粗暴。

**中序遍历**的递归黑盒：
```cpp
void inorder(Node* root) {
    if (root == nullptr) return;

    inorder(root->left);  // 🔪 第一刀！

    print(root->val);     // 打印自己
    inorder(root->right); // 🔪 第二刀！
}
```
**切完香肠：** 有 2 个递归调用，所以有 3 个 Stage（0, 1, 2）。不需要返回值，所以连 `ret_val` 都不用设。

**机械翻译版中序遍历：**
```cpp
struct Frame { Node* node; int stage; }; // 只有参数和书签

void inorder_iterative(Node* root) {
    stack<Frame> s;
    s.push({root, 0});

    while(!s.empty()) {
        Frame& f = s.top();
        
        if (f.node == nullptr) { // 对应 if (root == nullptr) return;
            s.pop();
            continue;
        }

        switch (f.stage) {
            case 0:
                f.stage = 1; // 夹好书签
                s.push({f.node->left, 0}); // 去左边
                break;
            case 1:
                cout << f.node->val; // 左边回来了，打印自己
                f.stage = 2; // 夹好书签
                s.push({f.node->right, 0}); // 去右边
                break;
            case 2:
                s.pop(); // 右边也回来了，代码执行完了，弹栈！
                break;
        }
    }
}
```

    void NonRecursion_In_2() {
        std::stack < frame > sta;
        sta.push({
            root,
            0
        });

            frame current = sta.top();
            sta.pop();
            switch (current.stage) {
                case 0: {
                    if (current.parameter == nullptr)
                        break;
                    current.stage++; // 跳出case、跳出while，这个弹掉，看下一个
