### 第一步：理解 `stage` 到底是什么？——它叫“书签”

假设你在看一本小说（执行函数）。
突然，你妈叫你去打酱油（发生了递归调用）。
你离开前会做什么？你会在你看的那一页**夹一个书签**，对吧？
等你打完酱油回来，你只要翻到书签那一页，就能**接着往下看**，而不会从第一页重新看。

代码里的 `stage`，就是这个**书签**。
因为递归函数在调用自己时，原来的函数**暂停了**。当子函数执行完毕返回时，原来的函数需要知道：“我刚才执行到哪一行代码了？接下来该执行哪行？”

---

### 第二步：“切香肠”法则（核心秘籍）

怎么确定一个递归有几个 `stage`？
**规则：寻找所有的“递归调用语句”，在它们后面重重地划一刀！**

被切出来的每一段，就是一个 `stage`。

我们拿最经典的**斐波那契数列**来切香肠：

```cpp
// 原始递归代码
int fib(int n) {
    if (n <= 1) return n;    // 前置逻辑

    int a = fib(n - 1);      // 遇到递归调用！🔪 第一刀切在这里！

    int b = fib(n - 2);      // 遇到递归调用！🔪 第二刀切在这里！

    return a + b;            // 后置逻辑
}
```

**切完之后，代码变成了 3 段（3 个 stage）：**

*   **Stage 0（开头到第一刀）：**
    判断 `n<=1`，如果成立直接返回；如果不成立，**准备调用 `fib(n-1)`**。
*   **Stage 1（第一刀到第二刀）：**
    刚才的 `fib(n-1)` 算完了，把结果存进变量 `a` 中。然后**准备调用 `fib(n-2)`**。
*   **Stage 2（第二刀到结尾）：**
    刚才的 `fib(n-2)` 算完了，把结果存进变量 `b` 中。计算 `a+b` 并返回，**函数彻底结束**。

> **死规律：** 一个函数里有 `K` 个递归调用，就会被切出 `K + 1` 个 Stage（分别是 0 到 K）。

### 第三步：机械化翻译模板（只做填空题）

现在我们把切好的香肠，填入我们的“万能模拟器”模板中。

**准备工作：定义备忘录（Frame）**
提取原函数的所有**参数**和**局部变量**，再加上 `stage`。
```cpp
struct Frame {
    int n;       // 参数 n
    int a, b;    // 局部变量 a 和 b
    int stage;   // 书签
};
```

**开始机械翻译（仔细看注释，全都是固定的套路）：**

```cpp
int fib_iterative(int n) {
    std::stack<Frame> s;
    s.push({n, 0, 0, 0}); // 初始调用压栈，stage永远是0
    
    int ret_val = 0;      // 模拟函数的返回值

    while (!s.empty()) {
        Frame& f = s.top(); // 拿出最上面的备忘录

        switch (f.stage) {
            case 0: // 【对应第一段香肠】
                if (f.n <= 1) {
                    ret_val = f.n; // 遇到 return，就把值塞进信箱
                    s.pop();       // 遇到 return，直接退栈（下班）
                    break;
                }
                // 没 return，说明要执行 fib(n-1) 了！
                f.stage = 1;              // 核心动作1：马上要走了，把自己的书签更新为下一阶段
                s.push({f.n - 1, 0, 0, 0}); // 核心动作2：把子任务压栈（调用子函数）
                break;

            case 1: // 【对应第二段香肠】
                // 醒来第一件事，接收刚才 fib(n-1) 算出的结果
                f.a = ret_val; 

                // 接着要执行 fib(n-2) 了！
                f.stage = 2;              // 更新书签
                s.push({f.n - 2, 0, 0, 0}); // 压栈
                break;

            case 2: // 【对应第三段香肠】
                // 醒来第一件事，接收刚才 fib(n-2) 算出的结果
                f.b = ret_val; 

                // 执行 return a + b;
                ret_val = f.a + f.b; // 把结果放入信箱
                s.pop();             // 任务全做完了，退栈（下班）
                break;
        }
    }
    return ret_val;
}
```

### 第四步：刻意练习（用“切香肠”秒杀二叉树遍历）

我们再回头看看你最初学的**二叉树遍历**。你学到的通常是很精简的非递归写法，但如果用我们的套路，其实极其简单粗暴。

**中序遍历**的递归黑盒：
```cpp
void inorder(Node* root) {
    if (root == nullptr) return;

    inorder(root->left);  // 🔪 第一刀！

    print(root->val);     // 打印自己
    inorder(root->right); // 🔪 第二刀！
}
```
**切完香肠：** 有 2 个递归调用，所以有 3 个 Stage（0, 1, 2）。不需要返回值，所以连 `ret_val` 都不用设。

**机械翻译版中序遍历：**
```cpp
struct Frame { Node* node; int stage; }; // 只有参数和书签

void inorder_iterative(Node* root) {
    stack<Frame> s;
    s.push({root, 0});

    while(!s.empty()) {
        Frame& f = s.top();
        
        if (f.node == nullptr) { // 对应 if (root == nullptr) return;
            s.pop();
            continue;
        }

        switch (f.stage) {
            case 0:
                f.stage = 1; // 夹好书签
                s.push({f.node->left, 0}); // 去左边
                break;
            case 1:
                cout << f.node->val; // 左边回来了，打印自己
                f.stage = 2; // 夹好书签
                s.push({f.node->right, 0}); // 去右边
                break;
            case 2:
                s.pop(); // 右边也回来了，代码执行完了，弹栈！
                break;
        }
    }
}
```
