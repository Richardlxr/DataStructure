# 层次遍历实践；求next指针

注意这里的遍历手法，可以int size，确保每次遍历开始的时候能数出来每一层的确切个数
```cpp
std::queue < int > index;
index.push(root);
while (!index.empty()) {
    int size = index.size();

    for (int i = 0; i < size; i++) {
        int curr = index.front();
        index.pop();

        // 只要不是这一层的最后一个节点，next指针就指向队列的新队首
        if (i < size - 1) {
            data[curr].next = index.front();
        }

        // 无论是不是最后一个节点，孩子入队逻辑是完全一样的
        if (data[curr].left != 0)
            index.push(data[curr].left);
        if (data[curr].right != 0)
            index.push(data[curr].right);
    }
}
```

# 或者利用满二叉树的性质DFS

```cpp
void DFS(Node * data, int curr, int next_index) {
    if (curr == 0) {
        return;
    }
    data[curr].next = next_index;
    DFS(data, data[curr].left, data[curr].right);
    DFS(data, data[curr].right, data[next_index].left);
}
```
