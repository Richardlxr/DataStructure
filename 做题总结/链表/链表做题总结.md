# 性能优化

## 一、尾插优化
```c
 void insert(T var, int index) {
        if (index < 0 || index > size) {
            throw std::out_of_range("Invalid Index!");
        }
        Node* p = new Node(var);
        Node* a = dummyhead;
        for (int i = 0; i < index; i++) {
            a = a->next;
        }
        p->next = a->next;
        a->next = p;
        if (index == size) {
            tail = p;
        }
        size++;
    }
    void push_to_tail(T var) {
        Node* p    = new Node(var);
        tail->next = p;
        tail       = p;
        size++;
    }
```

**通过维护tail来减少尾插的时间复杂度（不会TLE）**



## 二、==**从头往后**==一个个getElement优化

加迭代器（改链表类）

在 `Linkedlist` 的 `public` 区里，构造函数之后插入这段：

```c
    // ── 迭代器 ───────────────────────────────────────────────
    class Iterator {
        Node* curr;
      public:
        Iterator(Node* n) : curr(n) {}
        T&        operator*()  { return curr->var; }
        Iterator& operator++() { curr = curr->next; return *this; }
        bool operator!=(const Iterator& o) const { return curr != o.curr; }
    };
    Iterator begin() { return Iterator(dummyhead->next); }
    Iterator end()   { return Iterator(nullptr); }
    // ────────────────────────────────────────────────────────
```

然后把 `main` 里的加法循环换成迭代器版本：

```c
    Linkedlist<int>           arr3;
    int                       carry = 0;
    Linkedlist<int>::Iterator it1   = arr1.begin();
    Linkedlist<int>::Iterator it2   = arr2.begin();
    while (it1 != arr1.end()) {
        int sum = *it1 + *it2 + carry;
        arr3.push_to_tail(sum % 10);
        carry = sum / 10;   // 比 bool add1 更通用
        ++it1;
        ++it2;
    }
    if (carry) {
        arr3.push_to_tail(1);
    }
```

#### 对比

|               | 原来                        | 改后                 |
| ------------- | ------------------------- | ------------------ |
| `getElem(i)`  | 每次从头走 i 步，O(i)            | 不再调用               |
| 加法循环          | 调用 getElem 2n 次，**O(n²)** | 两个迭代器各走一步，**O(n)** |
| Iterator `++` | —                         | 只移动一个指针，**O(1)     |
