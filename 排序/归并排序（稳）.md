### 一、 基本思想（分治法）

归并排序采用了经典的分而治之（Divide and Conquer）策略。

- **分（Divide）：** 将待排序的元素分成大小大致相同的 2 个子集合，分别对这 2 个子集合进行递归排序。
    
- **合（Merge）：** 最终将排好序的子集合合并，成为所要求的排好序的完整集合。
    

### 二、 核心源码解析 (C++ 模板实现)

这里的代码使用了 C++ 的模板函数 `template <class KEY, class OTHER>`，这在处理包含关键字（Key）和其他附加数据（Other）的复杂结构体排序时非常常见。

#### 1. 合并函数 (`merge`)

`merge` 函数的作用是将两个**已经有序**的相邻表合并成一个有序表。
**双指针法**

C++

```c
template < class KEY, class OTHER >
    void merge(SET < KEY, OTHER > a[], int left, int mid, int right) {
        // 1. 动态开辟辅助空间 tmp，大小为待合并数组的总长度
        SET < KEY, OTHER > * tmp = new SET < KEY, OTHER > [right - left + 1];

        // i 指向左半部分起始点，j 指向右半部分起始点，k 为 tmp 数组的索引
        // 注意：根据幻灯片上下文，这里的 mid 参数实际上是传入的右半部分的起始索引 (mid+1)
        int i = left, j = mid, k = 0;

        // 2. 两表都未结束时，比较当前元素大小，较小的放入 tmp
        while (i < mid && j <= right) {
            if (a[i].key < a[j].key)
                tmp[k++] = a[i++];
            else
                tmp[k++] = a[j++];
        }

        // 3. 处理剩余元素：如果某一半部分没有结束，直接追加到 tmp 尾部
        while (i < mid) tmp[k++] = a[i++]; // 前半部分没有结束
        while (j <= right) tmp[k++] = a[j++]; // 后半部分没有结束

        // 4. 将排序好的 tmp 数组覆盖回原数组 a 的对应位置
        for (i = 0, k = left; k <= right;) {
            a[k++] = tmp[i++];
        }

        // 5. 释放动态分配的内存，防止内存泄漏
        delete[] tmp;
    }
```

#### 2. 递归主函数 (`mergeSort`)

控制“不断对半分”的主逻辑。

```c
template <class KEY, class OTHER>
void mergeSort(SET<KEY, OTHER> a[], int left, int right)
{
    int mid = (left + right) / 2;

    // 递归终止条件：如果 left == right，说明子集合只有 1 个元素，天然有序
    if (left == right) return; 

    // 分：递归调用，分别对左半边和右半边进行排序
    mergeSort(a, left, mid);
    mergeSort(a, mid + 1, right);
    
    // 合：将排好序的左半边和右半边合并
    // 注意这里传入的中间参数是 mid+1，对应了 merge 函数中的 j (右半边起点)
    merge(a, left, mid + 1, right); 
}
```

### 三、 算法复杂度与特性

根据幻灯片给出的递归方程：

- 当 $n \le 1$ 时，$T(n) = O(1)$
    
- 当 $n > 1$ 时，$T(n) = 2T(n/2) + O(n)$ （分成两半的时间 + 合并数组所花的时间）
    

推导出的核心性能指标如下：

- 🚀 **最坏时间复杂度：** $O(n \log n)$
    
- 🚀 **平均时间复杂度：** $O(n \log n)$
    
    _(注：归并排序的时间复杂度非常稳定，无论初始数据多么杂乱，哪怕是完全逆序，也是这个级别)_
    
- 💾 **辅助空间复杂度：** $O(n)$
    
    _(注：在 `merge` 操作中需要 `new` 一个长度与原数组相当的临时数组 `tmp`)_
    
- ⚖️ **稳定性：** **稳定 (Stable)**
    
    _(注：在遇到相同关键字大小的元素时，能保证它们在排序后的相对顺序不发生改变，这得益于 `a[i].key < a[j].key` 的严格小于判断)_
