## 核心思想：从低位到高位

基数排序最常用的方式是 **LSD（Least Significant Digit，从个位开始）**。

想象一下，你手里有一叠准考证号或者打乱的数字，你要怎么给它们排序？基数排序的做法是：

1. 先看所有数字的**个位数**，把它们扔进 $0 \sim 9$ 号对应的 10 个桶里，然后按桶的顺序收回来。
    
2. 再看所有数字的**十位数**，重复上面的分桶和收集。
    
3. 再看**百位数**、千位数……直到最高位处理完毕，整个数组就神奇地排好序了！
    

> **关键前提**：每一次针对单一位数的排序，必须是**稳定排序**（即如果两个数字这一位相同，它们原本的相对顺序不能变）。通常内部会使用**计数排序（Counting Sort）**或**桶排序**作为子过程。

## 动图/流程图直观演示

### 举个栗子 🌰

假设我们有一组数据：`[170, 45, 75, 90, 802, 24, 2, 66]`

- **第一步：按个位排序**
    
    - 看个位：17**0**, 04**5**, 07**5**, 09**0**, 80**2**, 02**4**, 00**2**, 06**6**
        
    - 分桶再收集后：`[170, 90, 802, 2, 24, 45, 75, 66]` （个位已经有序：0, 0, 2, 2, 4, 5, 5, 6）
        
- **第二步：按十位排序**
    
    - 看十位：1**7**0, **9**0, 8**0**2, 0**0**2, 0**2**4, 0**4**5, 0**7**5, 0**6**6
        
    - 分桶再收集后：`[802, 2, 24, 45, 66, 170, 75, 90]` （十位已经有序：0, 0, 2, 4, 6, 7, 7, 9）
        
- **第三步：按百位排序**
    
    - 看百位：**8**02, **0**02, **0**24, **0**45, **0**66, **1**70, **0**75, **0**90
        
    - 分桶再收集后：`[2, 24, 45, 66, 75, 90, 170, 802]`
        

**大功告成！** 数组已经完全有序。

## 算法复杂度与优缺点

### 1. 复杂度分析

- **时间复杂度**：
    
    $$O(d \cdot (n + k))$$
    
    - 其中 $n$ 是元素个数，$d$ 是最大元素的位数（比如最大数是 999，$d=3$），$k$ 是基数（几进制，十进制下 $k=10$）。
        
    - 如果 $d$ 和 $k$ 相对较小，基数排序甚至能达到接近线性的 $O(n)$ 速度，超越 $O(n \log n)$ 的比较排序极限。
        
- **空间复杂度**：
    
    $$O(n + k)$$
    
    ，因为需要额外的桶来临时存放数据。
    

### 2. 优缺点对比

|**优点**|**缺点**|
|---|---|
|⚡ **极快**：特定场景下比快排、归并还要快。|❌ **局限性强**：主要用于整数、字符串等可以拆分出“位”的数据。|
|🛡️ **稳定性**：是稳定排序，相同元素的相对位置不会错乱。|💾 **不省空间**：没法做到 In-place（原地排序），需要额外内存。|

# 源码

```cpp
#include <iostream>

// 根据 PPT 第一张，元素包含一个键值 key 和其他数据 other
template < class KEY, class OTHER >
    struct SET {
        KEY key;
        OTHER other;
    };

// PPT 第一张：单链表结点结构定义（不带头结点）
template < class OTHER >
    struct node {
        SET < int, OTHER > data;
        node * next;

        node() {
            next = NULL;
        }
        node(SET < int, OTHER > d): data(d) {
            next = NULL;
        }
    };

// PPT 第二、三张：基数排序核心实现
template < class OTHER >
    void bucketSort(node < OTHER > * & p) // p是链表头引用
{
    // bucket[10] 存储每个桶的头部，last[10] 存储每个桶的尾部，tail 用于重组链表
    node < OTHER > * bucket[10], * last[10], * tail;
    int i, j, k, base = 1, max = 0, len = 0;

    // 1. 找最大键值
    for (tail = p; tail != NULL; tail = tail - > next) {
        if (tail - > data.key > max) max = tail - > data.key;
    }

    // 2. 寻找最大键值的位数 (确定分配与收集的趟数)
    if (max == 0) {
        len = 0;
    } else {
        // PPT中直接对max进行了除10操作，因为后面不再需要原本的max值
        while (max > 0) {
            ++len;
            max /= 10;
        }
    }

    // 3. 执行 len 次的分配与重组
    for (i = 1; i <= len; ++i) {
        // 清空 10 个口袋（桶）
        for (j = 0; j <= 9; ++j) bucket[j] = last[j] = NULL;

        // 执行一次分配：将原链表中的结点按当前位（个位/十位/百位...）分配到对应的口袋中
        while (p != NULL) {
            k = p - > data.key / base % 10; // 计算当前位的数字 (0~9)
            if (bucket[k] == NULL) {
                bucket[k] = last[k] = p;
            } else {
                // PPT 简写为：last[k] = last[k]->next = p;
                // 含义是：让当前口袋尾结点的 next 指向 p，然后更新尾结点为 p
                last[k] - > next = p;
                last[k] = p;
            }
            p = p - > next;
        }

        // 执行重组（收集）：将 10 个口袋里的单链表按顺序重新串联起来
        p = NULL; // 重组后的新链表头
        for (j = 0; j <= 9; ++j) {
            if (bucket[j] == NULL) continue;
            if (p == NULL) {
                p = bucket[j]; // 第一个非空口袋作为新链表头
            } else {
                tail - > next = bucket[j]; // 后续非空口袋接到上一个口袋的尾部
            }
            tail = last[j]; // 更新当前总链表的尾指针
        }

        // 【补全点 1】：必须将重组后的链表尾部置为 NULL，否则最后一项可能会指向原有结点导致链表成环
        if (tail != NULL) tail - > next = NULL;

        // 【补全点 2】：每一趟结束，base 扩大 10 倍，用于下一趟取更高位（个位 -> 十位 -> 百位...）
        base *= 10;
    }
}
