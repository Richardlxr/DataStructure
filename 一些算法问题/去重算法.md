去重算法的实现主要取决于**数据是否允许排序**以及**对空间复杂度的要求**。

这里为你拆解两种最主流的底层实现方案：

## 方案一：快慢双指针法（针对已排序数组）

这是 C++ 标准库 `std::unique` 的底层核心逻辑。它的精髓在于**原地修改**，不需要开辟额外的内存空间，空间复杂度为 $O(1)$。

### 1. 核心思路

1. **慢指针（`slow`）**：指向当前已经确定“没有重复”的序列的末尾。
    
2. **快指针（`fast`）**：在前面冲锋陷阵，负责扫描整个数组。
    
3. 当快指针发现一个新数字和慢指针位置的数字**不相同**时，说明找到了一个新的唯一元素。此时让慢指针前进一格，并将快指针的数据复制过来。
    

### 2. 代码实现（C++ 风格，以 1-based 数组为例）

C++

```c
int unique_by_two_pointers(int arr[], int n) {
    if (n == 0) return 0;

    int slow = 1; // 慢指针：指向去重后新序列的末尾

    for (int fast = 2; fast <= n; fast++) { // 快指针：从第二个元素开始扫描
        if (arr[fast] != arr[slow]) {
            slow++; // 慢指针前进一步
            arr[slow] = arr[fast]; // 写入新的不重复元素
        }
    }

    return slow; // 返回去重后新数组的有效长度
}
```

> **复杂度分析**：
> 
> - **时间复杂度**：$O(N)$，只需挨个扫描一遍数组。
>     
> - **空间复杂度**：$O(1)$，直接在原数组上覆盖，极为节省内存。
>     

## 方案二：辅助哈希法（不改变原数组顺序）

如果你**不想破坏原数组的顺序（不想排序）**，但又想去掉重复的元素，可以使用一个辅助哈希集合（`std::unordered_set`）来记录哪些数字“见过面”。

### 1. 核心思路

1. 准备一个变量 `j` 记录新数组的写入位置，以及一个哈希表记录数字是否出现过。
    
2. 遍历原数组，每遇到一个数，先去哈希表里查。
    
3. 如果哈希表里没有，说明是第一次出现。把它塞进哈希表，同时让 `arr[j] = arr[i]`，然后 `j++`。
    
4. 如果哈希表里已经有了，直接跳过。
    

### 2. 代码实现

C++

```c
#include <unordered_set>

int unique_by_hash(int arr[], int n) {
    std::unordered_set < int > seen;
    int j = 1; // 记录去重后元素的写入位置

    for (int i = 1; i <= n; i++) {
        // 如果这个元素在之前没有出现过
        if (seen.find(arr[i]) == seen.end()) {
            seen.insert(arr[i]); // 标记为已处理
            arr[j] = arr[i]; // 原地覆盖写入
            j++; // 写入位置后移
        }
    }

    return j - 1; // 返回去重后新数组的有效长度
}
```

> **复杂度分析**：
> 
> - **时间复杂度**：平均 $O(N)$。
>     
> - **空间复杂度**：$O(N)$，需要一个哈希表来存储所有不同的元素。
>     

## 总结：如何选择？

- 如果你的数据**可以先排序**，或者**本身就是有序的**：闭眼选**双指针法**，速度最快，而且完全不耗额外内存。
    
- 如果题目**严格要求保留元素的原始相对顺序**：选择**辅助哈希法**。不过在线上测评（OJ）中，要注意数据量过大时哈希表的常数开销和潜在的冲突退化风险。
