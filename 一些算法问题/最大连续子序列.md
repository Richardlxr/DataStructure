**最大连续子序列问题（Maximum Subarray Problem）** 是数据结构和算法中的一个经典问题，经常用于讲解 **动态规划、分治法以及算法复杂度优化**。

---

## 1. 问题定义

给定一个整数序列：

$$  
A = [a_1, a_2, a_3, ..., a_n]  
$$

要求找到一个 **连续的子序列**：

$$ 
a_i + a_{i+1} + ... + a_j  
$$

使得这个子序列的 **和最大**。

注意：

- **必须是连续的**
    
- 子序列长度 ≥ 1
    

---

### 示例

数组：

```
[-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

最大连续子序列为：

```
[4, -1, 2, 1]
```

最大和：

```
4 + (-1) + 2 + 1 = 6
```

---

# 2. 暴力解法（O(n²) 或 O(n³)）


1. 枚举子序列起点
    
2. 枚举子序列终点
    
3. 计算这个子序列的和
    


## 1. 暴力算法的完整思路

假设数组

$$  
A = [a_0, a_1, ..., a_{n-1}]  
$$

所有连续子序列可以表示为

$$  
A[i..j]  
$$

其中

```
0 ≤ i ≤ j < n
```

所以算法是：

1️⃣ 枚举起点 `i`  
2️⃣ 枚举终点 `j`  
3️⃣ 把 `i..j` 的所有元素加起来

---

## 2. 三层循环代码

最原始写法：

```cpp
int maxSum = INT_MIN;

for(int i = 0; i < n; i++) {          // 枚举起点
    for(int j = i; j < n; j++) {      // 枚举终点
        int sum = 0;
        for(int k = i; k <= j; k++) { // 计算区间和
            sum += A[k];
        }
        maxSum = max(maxSum, sum);
    }
}
```

这里有 **三层循环**：

```
i -> n
j -> n
k -> n
```

---

## 3. 为什么是 O(n³)

我们数一下操作次数。

### 第一层

```
i = 0 → n-1
```

执行 **n 次**

---

### 第二层

对于每个 `i`

```
j = i → n-1
```

平均大约 **n/2 次**

---

### 第三层

每次计算区间和

```
k = i → j
```

平均 **n/2 次**

---

### 总操作

$$  
n × \frac{n}{2} × \frac{n}{2}  
$$

忽略常数：

$$  
O(n^3)  
$$

---

# 4. 更严谨的数学求和

精确计算：

$$  
\sum_{i=0}^{n-1} \sum_{j=i}^{n-1} (j-i+1)  
$$

结果：

$$  
≈ \frac{n^3}{6}  
$$

所以复杂度：

$$  
O(n^3)  
$$

---

## 5. 为什么后来可以优化到 O(n²)

观察：

每次都 **重新计算区间和** 很浪费。

例如：

```
A[i..j]
```

如果我们已经算出

```
A[i..j-1]
```

那么

```
A[i..j] = A[i..j-1] + A[j]
```

于是代码可以变成：

```cpp
for(int i = 0; i < n; i++) {
    int sum = 0;
    for(int j = i; j < n; j++) {
        sum += A[j];
        maxSum = max(maxSum, sum);
    }
}
```

这样就只剩：

```
两层循环
```

复杂度：

$$  
O(n^2)  
$$

---

# 3. 分治法（O(n log n)）

这个方法在很多 **算法教材（CLRS）** 里会讲。

思路：

最大子序列一定属于三种情况之一：

1️⃣ **完全在左边**

```
left ... mid
```

2️⃣ **完全在右边**

```
mid+1 ... right
```

3️⃣ **跨越中点**

```
左边后缀 + 右边前缀
```

因此：

```
max = max(
    左边最大子序列,
    右边最大子序列,
    跨越中点子序列
)
```

时间复杂度：

```
T(n) = 2T(n/2) + O(n)

= O(n log n)
```

# 4. 最优解：动态规划（Kadane 算法）O(n)

这是 **最经典、最优解法**。

核心思想：

**如果当前子序列和已经是负数，就重新开始。**

因为：

```
负数 + 后面的数 = 一定更小
```

所以不如直接丢弃。

---

### 状态定义

```
dp[i] = 以 i 结尾的最大子序列和
```

---

### 状态转移

```
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

解释：

两种选择：

1️⃣ **自己重新开始**

```
nums[i]
```

2️⃣ **接上前面的子序列**

```
dp[i-1] + nums[i]
```

---

### C++代码

```cpp
int maxSubArray(vector<int>& nums) {
    int current = nums[0];
    int best = nums[0];
	
    for(int i = 1; i < nums.size(); i++) {
        current = max(nums[i], current + nums[i]);
        best = max(best, current);
    }
	
    return best;
}
```

复杂度：

```
时间复杂度 O(n)
空间复杂度 O(1)
```
