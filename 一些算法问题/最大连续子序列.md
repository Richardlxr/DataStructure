**最大连续子序列问题（Maximum Subarray Problem）**是数据结构和算法中的一个经典问题，经常用于讲解 **动态规划、分治法以及算法复杂度优化**。

---

## 1. 问题定义

给定一个整数序列：

$$  
A = [a_1, a_2, a_3, ..., a_n]  
$$

要求找到一个 **连续的子序列**：

$$ 
a_i + a_{i+1} + ... + a_j  
$$

使得这个子序列的 **和最大**。

注意：

- **必须是连续的**
    
- 子序列长度 ≥ 1
    

---

### 示例

数组：

```
[-2, 1, -3, 4, -1, 2, 1, -5, 4]
```

最大连续子序列为：

```
[4, -1, 2, 1]
```

最大和：

```
4 + (-1) + 2 + 1 = 6
```

---

# 2. 暴力解法（O(n²) 或 O(n³)）

最直观的想法：

枚举所有可能的子序列。

### 思路

1. 枚举起点 `i`
    
2. 枚举终点 `j`
    
3. 计算 `i → j` 的和
    

### C++ 示例

```cpp
int maxSubArray(vector<int>& nums) {
    int maxSum = INT_MIN;

    for(int i = 0; i < nums.size(); i++) {
        int sum = 0;
        for(int j = i; j < nums.size(); j++) {
            sum += nums[j];
            maxSum = max(maxSum, sum);
        }
    }

    return maxSum;
}
```

复杂度：

```
时间复杂度 O(n²)
空间复杂度 O(1)
```

---

# 3. 分治法（O(n log n)）

这个方法在很多 **算法教材（CLRS）** 里会讲。

思路：

最大子序列一定属于三种情况之一：

1️⃣ **完全在左边**

```
left ... mid
```

2️⃣ **完全在右边**

```
mid+1 ... right
```

3️⃣ **跨越中点**

```
左边后缀 + 右边前缀
```

因此：

```
max = max(
    左边最大子序列,
    右边最大子序列,
    跨越中点子序列
)
```

时间复杂度：

```
T(n) = 2T(n/2) + O(n)

= O(n log n)
```

---

# 4. 最优解：动态规划（Kadane 算法）O(n)

这是 **最经典、最优解法**。

核心思想：

**如果当前子序列和已经是负数，就重新开始。**

因为：

```
负数 + 后面的数 = 一定更小
```

所以不如直接丢弃。

---

### 状态定义

```
dp[i] = 以 i 结尾的最大子序列和
```

---

### 状态转移

```
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

解释：

两种选择：

1️⃣ **自己重新开始**

```
nums[i]
```

2️⃣ **接上前面的子序列**

```
dp[i-1] + nums[i]
```

---

### C++代码

```cpp
int maxSubArray(vector<int>& nums) {
    int current = nums[0];
    int best = nums[0];

    for(int i = 1; i < nums.size(); i++) {
        current = max(nums[i], current + nums[i]);
        best = max(best, current);
    }

    return best;
}
```

复杂度：

```
时间复杂度 O(n)
空间复杂度 O(1)
```

---

# 5. 动态规划的直觉理解

举个例子：

```
[4, -1, 2, 1]
```

计算过程：

|i|nums[i]|current|best|
|---|---|---|---|
|0|4|4|4|
|1|-1|3|4|
|2|2|5|5|
|3|1|6|6|

最大就是：

```
6
```
