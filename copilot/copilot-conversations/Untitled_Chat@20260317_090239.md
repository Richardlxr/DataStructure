**ai**: 现代 CPU 内部有一个极其强悍的组件叫做 **分支预测器（Branch Predictor）**。它的工作原理像是一个记仇的门卫：如果你过去 100 次走左门，第 101 次它会毫不犹豫地提前把左门打开，让你全速冲过去。

---

让我们看看刚才那个循环里的 `if (i < n)` 在物理时间轴上是怎么表现的。

假设：

```cpp
n = 1000;
```

- 当 `i` 从 `0` 走到 `999` 时，`i < n` **连续 1000 次都是 True**。
- 当 `i = 1000` 时，`i < n` 变成 **False**（这里 CPU 会猜错 1 次，付出 15 个周期的代价，清空流水线）。
- 当 `i` 从 `1001` 走到 `1999` 时，`i < n` **连续 999 次都是 False**。

---

**物理结论**：在这个循环的 2000 次执行中，CPU 的分支预测器只会在中点（`i = 1000`）猜错 **仅仅 1 次**！剩下的 1999 次，CPU 都是满负荷、零延迟地像高铁一样冲过去的。这种极度规律的 `if`，对性能的影响可以忽略不计。

---

相比之下，什么是 CPU 极其害怕的“毒药 if”？

比如：

```cpp
if (nums[i] % 2 == 0)
```

（判断数组里的随机数字是否为偶数）。这个条件毫无规律可言，CPU 每次都在瞎猜，猜错率高达 50%，整条流水线会被频繁打断，性能暴跌。
