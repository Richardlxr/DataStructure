### 12.已知两个长度分别为m和n的升序链表，若将它们合并为一个长度为m+n的降序链表，则最坏情况下的时间复杂度是多少？
$O(m+n)$

**注**：这里要用头插法
```cpp
struct ListNode {
    int val;
    ListNode * next;
    ListNode(int x): val(x), next(nullptr) {}
};

ListNode * mergeToDescending(ListNode * l1, ListNode * l2) {
    // 我们的结果链表头，初始为 NULL，它将作为“新楼”的基座
    ListNode * resultHead = nullptr;
    ListNode * p1 = l1;
    ListNode * p2 = l2;

    // 第一阶段：当两个链表都不为空时，进行“抢夺”
    while (p1 != nullptr && p2 != nullptr) {
        ListNode * target = nullptr;

        // 挑选较小的节点（为了让最终降序，必须先放小的，后放大的）
        if (p1 - > val <= p2 - > val) {
            target = p1;
            p1 = p1 - > next; // 物理指针向前移动，保护好剩余的链表
        } else {
            target = p2;
            p2 = p2 - > next;
        }

        // --- 核心：头插法逻辑 ---
        target - > next = resultHead; // 让⭐新节点的 next 指向当前“楼顶”
        resultHead = target; // 更新“楼顶”位置为新插入的节点
    }

    // 第二阶段：处理剩余的节点（注意！这里依然要用头插，否则会变成局部升序）
    ListNode * remaining = (p1 != nullptr) ? p1 : p2;
    while (remaining != nullptr) {
        ListNode * target = remaining;
        remaining = remaining - > next;

        target - > next = resultHead;
        resultHead = target;
    }

    return resultHead;
}
```


### 6. 链表逆序
```cpp
int reverseAndCount() {
    // 1. 拦截异常：如果是空表，或者只有 Dummy Head 没有数据节点，长度直接为 0
    if (head == nullptr || head - > next == nullptr) return 0;

    int length = 0;

    // 2. 物理定位：
    // prev 初始化为 nullptr，它将成为新链表的尾部（NULL）
    ListNode * prev = nullptr;
    // curr 从第一个“真实数据节点”开始进攻
    ListNode * curr = head - > next;

    while (curr != nullptr) {
        // 战术动作 1：在切断 curr 的后路之前，派 nextTemp 侦察兵记住下一个物理坐标
        ListNode * nextTemp = curr - > next;

        // 战术动作 2：指针物理回拨（逆序核心）
        curr - > next = prev;

        // 战术动作 3：防线整体向前推进
        prev = curr;
        curr = nextTemp;

        // 战术动作 4：记录真实击杀数（因为 curr 是从 head->next 开始的）
        length++;
    }

    // 此时，curr 已经坠入虚无（nullptr），而 prev 停留在原链表的最后一个节点。
    // 战术动作 5：重新锚定地基！让 Dummy Head 指向新的头节点（prev）
    head - > next = prev;

    return length;
}
```

### 7. 倒数第k个元素

**注意一下不要以dummyhead为起点，一定要以真实数据做起点**
```cpp
ListNode * findKthFromEnd(ListNode * head, int k) {
    // 基础防御：空链表或非法的 k
    if (head == nullptr || head - > next == nullptr || k <= 0) return nullptr;

    // 战术调整：双指针全部从【第一个真实节点】起跑！远离 Dummy Head！
    ListNode * fast = head - > next;
    ListNode * slow = head - > next;

    // 第一阶段：拉开物理步长差（让 fast 先走 k 步）
    while (k > 0 && fast != nullptr) {
        fast = fast - > next;
        k--;
    }

    // 物理防线：如果循环结束 k 依然大于 0，说明链表真实长度根本不够 k！
    if (k > 0) {
        // throw std::out_of_range("Invalid K!"); // 抛出异常
        return nullptr; // 或者返回 NULL 表示找不到
    }

    // 第二阶段：齐步走，直到 fast 彻底坠入虚无 (nullptr)
    // 此时不需要判断 fast->next，彻底杜绝了 Segfault 的风险
    while (fast != nullptr) {
        slow = slow - > next;
        fast = fast - > next;
    }

    // 此时的 slow 就是绝对安全的倒数第 K 个节点
    return slow;
}
```
