#### 1. 概念层：什么是顺序表？
*   **物理结构**：内存中**连续**的一块存储空间（就像一排紧挨着的座位）。
*   **结构体定义**：它不仅包含一个数组，还包含一个记录当前元素个数的变量（`length`）。
*   **分类**：
    *   静态顺序表（用定长数组实现，大小写死了）。
    *   动态顺序表（用指针+`malloc`/`new`实现，不够了可以扩容）。

#### 2. 操作层：增删改查（CRUD）—— **绝对重点！**
*   **按位查找 (Get)**：直接通过下标访问，时间复杂度 **O(1)**。（这是顺序表最大的优点：随机访问）。
*   **按值查找 (Find)**：从头到尾遍历比对，时间复杂度 **O(n)**。
*   **插入 (Insert)**：在第 `i` 个位置插入元素。**难点**：需要把第 `i` 个及之后的元素全部**往后挪**。时间复杂度 **O(n)**。
*   **删除 (Delete)**：删除第 `i` 个位置的元素。**难点**：需要把第 `i+1` 个及之后的元素全部**往前挪**。时间复杂度 **O(n)**。

#### 3. 理论层：优缺点分析（考试/面试必考）
*   **优点**：支持随机访问（查得快）；存储密度高（不需要额外存指针）。
*   **缺点**：插入和删除慢（要大面积挪动元素）；需要预先分配大块连续内存（容易造成浪费或溢出）。

#### 双指针法
#双指针法
## 1. 算法思路
> [!info] 核心思想
> 两侧向中间走：设两个指针（或下标），一个在头（`i=0`），一个在尾（`j=length-1`），互相交换元素，然后往中间走，直到相遇。（示例：顺序表逆置）
> 从一侧向另一头走：两个指针都从头向后同时遍历，但是做的事情不一样、走的速度不一样
> 两个指针在两个数组里面，分别向后遍历。（示例：顺序表删除特定值的元素）

## 2. 复杂度分析
- **时间复杂度**: $O(n)$
- **空间复杂度**: $O(1)$

**题目 2：顺序表逆置**
*   **描述**：已知一个顺序表 `L`，请编写一个函数，将表中的元素原地逆置（不能开辟新的数组空间，空间复杂度为 O(1)）。
*   **例如**：原表为 `[1, 2, 3, 4, 5]`，逆置后变为 `[5, 4, 3, 2, 1]`。


**题目 3：删除特定值的所有元素**
*   **描述**：长度为 `n` 的顺序表 `L`，编写一个时间复杂度为 O(n)、空间复杂度为 O(1) 的算法，删除表中所有值为 `x` 的数据元素。
*   **导师思路**：千万不要遇到一个 `x` 就调用一次普通的 Delete 函数，那样时间复杂度会变成 O(n²)！**正确做法是“双指针法”**：用一个变量 `k` 记录当前不等于 `x` 的元素个数，边遍历边把不等于 `x` 的元素往前放到 `k` 的位置上。
```cpp
void find_del(int num)
{
	int *p1 = begin;
	int *p2 = begin;
	int count = 0;
for (int i = 0; i < length; i++) // i<length!,虽然会越界，但是不重要，最后一位能检查到
{
if (*p2 != num)
{
	*p1 = *p2;
	p1++;
	p2++;
}
else
{
	count++;
	p2++;
}
length -= count;
}
```

#### 逆向双指针

**题目 4：合并两个有序顺序表**
*   **描述**：有两个**递增有序**的顺序表 A 和 B，请编写函数将它们合并成一个新的顺序表 C，且 C 依然是递增有序的。
*   **例如**：A = `[1, 3, 5]`，B = `[2, 4, 6]`，合并后 C = `[1, 2, 3, 4, 5, 6]`。
*   **导师思路**：用三个变量 `i`, `j`, `k` 分别指向 A, B, C。比较 A[i] 和 B[j] 的大小，谁小就把谁放进 C[k] 里，直到其中一个表走完，再把另一个表剩下的元素全贴到 C 的末尾。
```cpp
static Seqlist merge(const Seqlist &sq1, const Seqlist &sq2)

{
// 创建一个足够大的新表
Seqlist sq(sq1.get_length() + sq2.get_length());
// 我们只需要拿它们的数组指针
int *data1 = sq1.get_start();
int *data2 = sq2.get_start();
int i = 0; // sq1 的下标
int j = 0; // sq2 的下标 
// 1. 两个表都没走完时，谁小就 append 谁
while (i < sq1.get_length() && j < sq2.get_length())
{
if (data1[i] <= data2[j])
{
sq.append(data1[i]);
i++;
}
else
{
sq.append(data2[j]);
j++;
}
}
// 2. 扫尾工作：如果 sq1 还有剩的，全塞进去
// (注意：因为上面的 while 结束了，这两个 while 绝对只会执行其中一个)
while (i < sq1.get_length())
{
sq.append(data1[i]);
i++;
}
// 3. 扫尾工作：如果 sq2 还有剩的，全塞进去
while (j < sq2.get_length())
{
sq.append(data2[j]);
j++;
}
return sq; // 完美返回
}
```


##### 思考：如何不引入中间变量，减少空间复杂度？
###### 算法：逆向双指针

###### 1. 算法思路
> [!info] 核心思想
> 指针逆向，从尾到头的遍历，同时选定的元素直接从nums1的尾部往前排序，这样保证尾部空间永远充足，向前推进
###### 2. 复杂度分析
- **时间复杂度**: $O(n+m)$
- **空间复杂度**: $O(1)$

###### 3. 代码实现
```cpp
class Solution
{
public:
void merge(vector<int> &nums1, int m, vector<int> &nums2, int n)
{
int p1 = m - 1, p2 = n - 1;
int tail = m + n - 1;
int cur;
while (p1 >= 0 || p2 >= 0)
{
if (p1 == -1)
{
cur = nums2[p2--];
}
else if (p2 == -1)
{
cur = nums1[p1--];
}
else if (nums1[p1] > nums2[p2])
{
cur = nums1[p1--];
}
else
{
cur = nums2[p2--];
}
nums1[tail--] = cur;
}
}
};
// 无需中间变量，直接填，空间复杂度减小
```
